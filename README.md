# marketable-it-skills

This is the base repository of the **Marketable IT Skills (MITS)** GitHub organization. It holds organization-level content rather than application code:

- **[`profile/README.md`](profile/README.md)** — the landing page shown on the organization's public GitHub profile.
- **[`about.md`](about.md)** — a short description of the MITS project, its goals, partners, and funding.
- **[`CONTRIBUTING.md`](CONTRIBUTING.md)** — how to contribute project tasks and tutorials, or report issues.

## About MITS

**Marketable IT Skills: Integrating Real-World Challenges into Vocational Education (MITS)** is an Erasmus+ co-funded project that supports IT vocational education with an openly available collection of realistic project tasks and a web application that provides evaluation support. The project is coordinated by the **HTTP Foundation** (Hungary) in cooperation with **Business College Helsinki** (Finland).

Learn more on the [organization profile](profile/README.md) or in [`about.md`](about.md).
