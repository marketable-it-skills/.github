# Marketable IT Skills (MITS)

### Integrating Real-World Challenges into Vocational Education

[![Funded by Erasmus+](https://img.shields.io/badge/Funded%20by-Erasmus%2B-004494)](https://erasmus-plus.ec.europa.eu/)

[![Contributions welcome](https://img.shields.io/badge/contributions-welcome-brightgreen)](https://github.com/marketable-it-skills/.github/blob/main/CONTRIBUTING.md)

**Marketable IT Skills (MITS)** is an Erasmus+ co-funded project that strengthens IT vocational education through an openly available, continuously growing collection of realistic project tasks and a web application that supports their evaluation. The tasks are designed to reflect labour-market expectations, simulate real workplace challenges, and support talent management in IT education.

The project's task collection draws upon the competition materials of **WorldSkills**, **EuroSkills**, and various national and international skills competitions.

## What you will find here

This GitHub organization hosts the open components of the MITS ecosystem:

- **[MITS Platform](https://skillsit.eu)** — the web application that publishes project tasks and tutorials and provides evaluation support.
- **[Contribution Guide](https://github.com/marketable-it-skills/.github/blob/main/CONTRIBUTING.md)** — how to contribute your own project tasks and tutorials, or report issues.
- **[Project Task Updater Toolkit](https://github.com/marketable-it-skills/mits-project-task-updater-toolkit)** — AI-supported tooling that helps bring project tasks into the standardized MITS format.
- **[Project Task Template](https://github.com/marketable-it-skills/mits-project-task-template)** — a starting-point repository with the folder and file structure expected by MITS.

## Who MITS is for

- **Educators and trainers** looking for realistic, competition-grade project tasks to use in IT vocational training.
- **Students and competitors** who want to practise with tasks that simulate real workplace challenges.
- **Contributors** who hold their own project tasks or tutorials and want to share them with the community.

## Contributing

MITS is an open-source–spirited project. We welcome contributions from anyone who shares the values of MITS — open source, knowledge sharing, and social responsibility — and can provide real added value to the project.

You can contribute by:

1. Updating and contributing your own project tasks.
2. Creating and contributing MITS tutorials.
3. Improving existing project tasks and tutorials by reporting issues.

See the **[Contribution Guide](https://github.com/marketable-it-skills/.github/blob/main/CONTRIBUTING.md)** for the full process.
