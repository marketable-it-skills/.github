# MITS Contribution Guide

The MITS project is an open-source–spirited project, welcoming collaboration from anyone who shares the values of MITS — such as open source, knowledge sharing, and social responsibility — and has the professional background that enables them to provide real added value to the project.

This guide describes in detail the opportunities, forms, and ways of collaboration.

There are currently the following ways to contribute to MITS:

1. Updating your own self-developed and intellectually owned project tasks (e.g. module tasks from national or preparatory competitions) and contributing them to the community.

2. Creating a MITS tutorial and contributing it to the community.

3. Improving the project tasks and tutorials already in MITS.

## Licensing and intellectual property

You may only contribute project tasks and tutorials whose intellectual property rights you fully hold.

Contributed project tasks and tutorials are published under the [Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0)](https://creativecommons.org/licenses/by-nc/4.0/) license. In practice this means:

- You retain the copyright and authorship of your contribution, and you may continue to use it freely for any purpose, including commercially.
- By contributing, you grant MITS and the community the right to use, modify, and distribute your contribution for non-commercial purposes, with appropriate attribution to you as the author.

By submitting a contribution you confirm that you hold all the rights necessary to do so and that you agree to publish it under these terms.

## Before you start

Before contributing, make sure you have the following:

- A **MITS platform account** to submit contributions and report issues.
- The **intellectual property rights** to whatever you contribute (see [Licensing and intellectual property](#licensing-and-intellectual-property)).
- Familiarity with the **MITS Project Task Standardization Guide** if you are contributing a project task.

## Contributing a project task

### What kinds of tasks can be contributed to MITS?

In general, tasks that can be contributed to the MITS project are those that

- you fully hold the intellectual property rights to
- follow the spirit and style of the module tasks (test projects) of skills competitions (e.g. EuroSkills and WorldSkills)
- harmonize with the requirements framework (Technical Description) of the relevant skill area (e.g. web technology) for WorldSkills or EuroSkills
- describe a project task that well simulates current workplace challenges
- may be suitable for acquiring or practicing the skills of a given professional area in IT vocational training

We especially welcome the tasks of national qualifiers and training competitions that meet the WorldSkills standard.

### Updating the tasks

#### What requirements must the contributed project task meet?

In order for the contributed project task to be added to MITS, it must be brought into a form that complies with the requirements of the [MITS Project Task Standardization Guide](https://github.com/marketable-it-skills/mits-project-task-updater-toolkit/blob/main/guides/MITS_PROJECT_TASK_STANDARDIZATION_GUIDE.md), that is, it

- uses the specified folder and file structure and naming
- structures the project task description (`project-description.md`) according to the requirements detailed in the MITS Project Task Standardization Guide
- has a detailed marking scheme (`marking-scheme.json`) in the format described in the MITS Project Task Standardization Guide
- includes a `metadata.json` that contains all the metadata described in the MITS Project Task Standardization Guide and complies with the prescribed format

#### The process of updating and submitting the tasks

Updating the tasks can be carried out with traditional methods as well, but it is recommended to use the AI-supported tools of the [MITS Project Task Updater Toolkit](https://github.com/marketable-it-skills/mits-project-task-updater-toolkit). The process consists of the following main steps:

1. Creating your own public repository with the folder and file structure that complies with the MITS Project Task Standardization Guide. It is recommended to create the repository based on the [MITS Project Task Template](https://github.com/marketable-it-skills/mits-project-task-template) repo.
2. Updating the original task manually or with the help of the MITS Project Task Updater Toolkit and uploading it to the new repo.
3. Submitting the project task. After logging in on the MITS platform, this can be initiated from your own menu, which is accessible by clicking the avatar shown on the right side of the header, by selecting the Contribute menu item and then clicking the `Submit a Project Task` button.
4. If the project passes the formal check, it is set to draft status.
5. The MITS project team reviews the submission in detail. We notify you of the outcome: whether your contribution is accepted, rejected, or needs additional modifications before it can be accepted. If modifications are needed, you can update your repository and resubmit.
6. Once accepted, the project task is published on the platform.

## Creating a MITS tutorial

A detailed description for creating and submitting MITS tutorials is also coming soon. Until it is available, the already completed tutorials can be used as a reference. A completed tutorial that is available in your own public repo can be submitted similarly to submitting project tasks, by clicking the `Submit a Tutorial` button.

## Improving project tasks and tutorials

If you find a bug or something to improve in any published project task or tutorial, you can report it by submitting an Issue. On the MITS Platform this can be initiated by clicking the `Report Issue` button at the given task or tutorial. For tasks and tutorials stored in public repositories, this can also be done by creating a GitHub issue.
